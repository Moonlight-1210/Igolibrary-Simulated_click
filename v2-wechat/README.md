# v2：PC 微信内置浏览器后台抢座（新手极简版）

> 不用装电脑知识：有**免安装压缩包**可以直接下载双击使用；如果你想从源码运行，也只需要点一下一键装依赖脚本。
> 完整版本对比与风险提示请看根目录 [README.md](../README.md)。

---

## 方法一：小白免安装版（推荐，不用装 Python）

1. 去仓库 Releases 下载 **`seat-grabber-v2.0.2-win-x64.zip`** 并**完整解压**。
2. 登录 **电脑版微信**（3.9 或 4.x 均支持）→ 点开「我去图书馆」→「去选座」→ 进到你要抢的场馆 **座位图页面**。
3. 点击微信浏览器右上角 **`[↗]`** 弹出独立小窗（把小窗拉大一点确保座位都在画面里；之后可压在其他软件下面，但**别点最小化**）。
4. 双击解压后的 **`图书馆后台抢座助手.exe`** → 确认顶部显示 **`已连接 · XXX座`** → 点 **「▶ 开始运行」**！

---

## 方法二：源码运行（Windows 10/11 + Python 3.10+）

1. **一键装依赖**：双击 **`install_deps.bat`**（自动装 `Pillow` 与 `numpy`，超时会自动用清华镜像）。
2. **首次 5 秒安全测试（推荐）**：微信小窗停在座位图页，双击 **`run_test_click.bat`**（只点 3 次「刷新」，不点座位、不点确认）。
3. **打开图形界面**：双击 **`start_gui.bat`** 即可使用。

### 命令行与热键

- **全局热键**：运行中随时按 **`F9` 暂停**、**`F10` 继续**。
- **快捷脚本**：`start_monitor.bat`（只蹲守提醒）、`start_live.bat`（自动抢座 `0.8~1.5s`）、`start_fast.bat`（冲刺 `0.4~0.8s`）。
- **常用参数**（`python wechat_grab_v2.py`）：
  - `--mode monitor|live`：仅监控提醒 / 自动抢座
  - `--prefer 001,A01,1-05`：优先抢指定座位号（支持纯数字与字母+数字编号；留空则随机选空座）
  - `--safe` / `--fast`：切换稳健（`2.0~3.5s`）/ 冲刺（`0.4~0.8s`）节奏
  - `--minutes 120`：运行时长（`0` 表示不限时）
  - `--no-beep`：关闭提示音

# 我去图书馆 · 抢座助手（v2 PC 微信后台版 + v1 浏览器版）

> 支持任意使用「我去图书馆」平台的学校与场馆（纯座位图+文字识别，不绑定任何学校）。
> 本仓库同时提供 **v2（电脑微信后台版，小白推荐）** 与 **v1（Playwright 浏览器版，保留供参考）**，请先看下方对比再选。

---

## 一、v2 和 v1 怎么选？

| 对比项 | **v2：电脑微信后台版（推荐）** | **v1：Playwright 浏览器版（保留）** |
| :--- | :--- | :--- |
| **运行方式** | 电脑微信自带浏览器小窗（100% 真微信环境） | 用代码另开本机 Chrome 并手动粘贴登录链接 |
| **防风控能力** | **更稳**：原生微信环境与登录态，无浏览器自动化注入特征 | **较易被拦**：脱离微信环境，实测容易触发「访问行为异常」拦截 |
| **使用体验** | **零鼠标占用、不抢焦点**：独立小窗可压在别的窗口底下后台跑 | 需保持受控 Chrome 窗口存在 |
| **选座精度** | 自动读取全图座位号（支持纯数字 `001` 及 `A01`/`1-05` 等），支持指定偏好座位、防「加载中」误判、风控自动熔断 | 依赖网页元素定位 |
| **操作难度** | **提供免安装压缩包**，不用装 Python，解压双击 `.exe` 就能用图形界面 | 提供免安装压缩包，内置网页控制台 |
| **手机远程** | 不支持（仅在电脑本地运行） | 支持局域网 / Cloudflare Tunnel 手机远程操作 |
| **适用系统** | **Windows 10 / 11 + PC 微信（3.9 / 4.x 均支持）** | Windows 10 / 11 + Google Chrome |

### 各自优缺点一句话总结

- **v2 优点**：在真实电脑微信里跑，最接近真人环境；图形界面直观；不抢鼠标、不占屏幕、小窗被挡住也能正常识别；遇到弹窗或风控自动停手保号。
- **v2 缺点**：只支持 Windows 电脑 + PC 微信；不支持手机远程网页控制；每次开跑前需要先自己在微信里点进目标场馆座位图并点一下弹出小窗；电脑不能锁屏/休眠，小窗不能点最小化。
- **v1 优点**：有 Web 控制台，支持手机远程开关、自动拉取场馆列表和取消预约。
- **v1 缺点**：脱离微信内置浏览器，平台很容易识别出异常环境并限制账号；授权链接约 2 小时过期，需要反复续期。

## 二、v2 小白傻瓜式使用教程（推荐）

### 方式 A：小白免安装版（推荐，不用装 Python）

1. **下载压缩包**：
   - 前往 Releases 下载 **[seat-grabber-v2.0.1-win-x64.zip](https://github.com/Moonlight-1210/Igolibrary-Simulated_click/releases/download/v2.0.1/seat-grabber-v2.0.1-win-x64.zip)**
   - **一定要先全部解压到一个普通文件夹**（不要直接在压缩包预览窗口里双击运行）。
2. **微信打开座位图**：
   - 打开电脑版微信（3.9 或 4.x 都行）并登录；
   - 在微信里点开「我去图书馆」→ 点「去选座」→ 点进你要抢的那个场馆，停在**能看到座位图和底部「确认选座」按钮**的页面。
3. **把浏览器弹出成独立小窗**：
   - 点击微信内置浏览器右上角的 **`[↗]`** 按钮，让它变成一个独立小窗；
   - 把这个小窗拉大一点，**确保你想抢的座位都能看到**（别被滚动条裁掉）；
   - 之后你可以把这个小窗拖到屏幕边上，或者**直接用其他软件窗口挡住它**（微信聊天主窗口关掉也行）；
   - **唯一注意：千万不要点小窗右上角的最小化（`—`）**，缩进任务栏会让电脑暂停渲染画面。
4. **启动助手开始抢座**：
   - 双击解压文件夹里的 **`图书馆后台抢座助手.exe`**；
   - 看到顶部绿色字样 **`已连接 · XXX座`**，右边能看到座位图预览，就说明连上了；
   - 新手建议先选 **「仅监控提醒」** 试跑几分钟，确认正常后再切 **「自动抢座」**，点 **「▶ 开始运行」** 就可以去干别的事了！

---

### 方式 B：源码运行（适合电脑已有 Python 或想自己改代码）

需要 Windows 10 / 11 + Python 3.10+（自带 `tkinter`）：

1. **一键装依赖**：双击 `v2-wechat/install_deps.bat`（自动安装 `Pillow` 和 `numpy`，失败会自动切换清华源）。
2. **首次 5 秒安全测试（推荐）**：按照上面第 2、3 步把微信独立小窗准备好，双击 `v2-wechat/run_test_click.bat`。它**只会点 3 次「刷新」按钮，绝不会点任何座位或「确认选座」**，用来确认你电脑上后台抓图和点击都正常。
3. **启动图形界面**：双击 `v2-wechat/start_gui.bat`（无黑框直接打开界面）。
4. **命令行快捷启动（可选）**：
   - `v2-wechat/start_monitor.bat`：仅监控提醒（`0.8~1.5s` 随机刷新，发现空座响铃+截图，不点预约）
   - `v2-wechat/start_live.bat`：自动抢座（`0.8~1.5s` 随机刷新）
   - `v2-wechat/start_fast.bat`：冲刺模式（`0.4~0.8s` 随机刷新，仅放座高峰短时用）
   - 高级参数可运行 `python wechat_grab_v2.py --help`（支持 `--prefer A01,A02` 指定优先座位、`--safe` `2.0~3.5s` 稳健节奏、`--no-beep` 静音）。

### 三、小白常见问题（FAQ）

1. **顶部一直显示「未检测到微信小窗」怎么办？**
   - 确认你已经在电脑微信里点开了图书馆网页，并且停在能看到座位图的页面；
   - 强烈建议点一下浏览器右上角 **`[↗]`** 弹出成独立小窗再点「检测微信窗口」；
   - 确认没有把微信小窗最小化到任务栏。
2. **运行的时候会抢我的鼠标、影响我写作业或打游戏吗？**
   - **不会**。程序全程通过 Windows 消息在后台点「刷新」和选座，不会移动你的真实鼠标指针，也不会把微信抢到最前面；你把微信小窗压在别的软件底下一样正常抢座。
3. **怎么随时暂停或停止？**
   - 在任何软件界面直接按键盘 **`F9` 暂停**、**`F10` 继续**；也可以点助手窗口里的按钮停止。
4. **日志里出现红字「熔断停止」或预约后跳出广告页怎么办？**
   - 红字「熔断停止」是保号保护机制，说明页面弹窗报错（例如「访问行为异常」）或连续多次未抢到；先点助手右上角 **「打开截图目录」** 查看最后一张截图里的提示，**切忌强行反复重开硬点**；
   - 点击「确认选座」后，平台通常会跳转到**签到二维码页**，有时也会弹出**广告页**——这属于正常预约跳转，**不是被风控**，助手会显示绿色的「选座成功 / 已选座/跳转」并自动停止，切回微信窗口查看即可。
5. **Windows 弹出「Windows 已保护你的电脑」蓝框怎么办？**
   - 因为个人开源程序没有花钱买微软数字签名，点蓝框上的 **「更多信息」→「仍要运行」** 即可；如果不放心，完全可以使用上方的「方式 B：源码运行」。

## 四、风险与局限性（重要，使用前必读）

1. **平台风控与封号风险（最关键）**：
   - 即使运行在真实 PC 微信内置浏览器内，平台除了检测浏览器环境外，还会检测**刷新频率与异常行为**；
   - 长时间高频率刷屏（如持续低于 `0.8s`）、或在账号受限期间反复点击「确认选座」，依然可能触发「检测到访问行为异常」拦截甚至导致账号被封禁；
   - 平时长期挂机建议用 **标准（`0.8~1.5s`）** 或 **稳健（`2.0~3.5s`）** 节奏，只在整点放座前后短时切 **冲刺（`0.4~0.8s`）**；遇到异常熔断立刻停手查看截图。
2. **系统与电源限制**：
   - v2 仅支持 **Windows 10 / 11**（不支持 macOS / Linux）；
   - 微信独立小窗**可以被其他窗口遮挡，但不能最小化到任务栏**，电脑也不能**锁屏、熄屏休眠**（请在系统电源设置里调成接通电源不睡眠），否则 Windows 会停止渲染窗口画面导致抓图全黑。
3. **网页改版与微信更新兼容风险**：
   - v2 依赖 PC 微信（3.9 / 4.x）的 Chromium 渲染窗口结构以及网页内的文字标识（「刷新」「确认选座」）与座位方块颜色；若微信大版本更新或平台改版前端配色/文案，需要同步更新适配。
4. **大场馆可视区域限制**：
   - 后台抓图只能识别当前浏览器视野里渲染出来的座位；如果场馆很大、有上下左右滚动条，请先把独立小窗尽量拉大，确保目标座位区域完整显示在视野内。
5. **合法合规声明**：
   - 本工具仅作学习 Windows 桌面自动化技术之用，请遵守所在学校图书馆及平台规定，不要恶意占座或用于商业用途。

## 五、v1：Playwright 浏览器版（保留，按需选用）

> 基于 Playwright 驱动本机真实 Chrome 模拟点击的早期版本。支持任意使用「我去图书馆」平台的学校与场馆，自带 Web 控制台与手机远程控制。

### v1 功能

- **微信授权登录**：手机微信扫「微信授权二维码」→ 复制带 `code=` 的链接 → 粘贴解析登录（也可用手机快传）
- **自动加载场馆**：登录后自动读取你所在学校的场馆列表（不同学校各自显示自己的场馆）
- **首页控制台**：账号信息、当前预约、签到截止倒计时、数据刷新
- **抢座**：监控官方座位图，发现空座后点击座位 → 确认选座（全程真实点击）
- **自动保护**：预约被平台风控拦截时自动停止；抢到后自动停止并提醒
- **取消预约**：在官方网页上点「取消预定」→「确定」（真实点击）
- **远程控制**：手机浏览器打开同一页面即可远程操作（局域网 / Cloudflare Tunnel 公网均可）
- **实时日志**

### v1 工作原理

程序用 Playwright 驱动本机真实 Chrome，**打开官方网页，所有平台请求都由页面自己发出**：

1. **登录**：用真实浏览器打开微信授权接口完成换 cookie，登录与后续使用处于同一浏览器环境；
2. **抢座**：模拟真人进入流程（首页 → 选座 → 座位图），点击页面「刷新」→ 发现空座 → 点击座位 → 点击「确认选座」；
3. **数据读取**（账号/预约/场馆）：真实浏览器打开官方网页，由页面自己请求，程序只读取页面请求的响应；
4. **取消预约**：点击「取消预定」→「确定」。

> 浏览器使用本机 Chrome 原生 UA（不伪造），并做基础反自动化特征处理；不直接调用平台 GraphQL 接口。

### v1 环境要求

#### 源码运行

- Windows 10/11
- Node.js 18+
- Google Chrome（Playwright 使用本机 Chrome）

### v1 安装与运行

```bash
npm install
npm install playwright-core
```

双击 `启动.bat`，或命令行运行：

```bash
node server.js
```

启动后会自动打开浏览器控制台；若没有自动打开，手动访问 http://127.0.0.1:7789

### v1 使用步骤

1. 点「登录」→ 手机微信扫微信授权二维码 → 完成授权 → 复制跳转后带 `code=` 的链接 → 粘贴 → 「从链接解析登录」；
2. 登录成功后，场馆下拉框会**自动加载你所在学校的场馆**，选择一个场馆；
3. 设置刷新间隔（默认 1~1.5 秒）、运行时长（默认 60 分钟）；
4. 点「开始抢座」，程序会在官方网页上真实点击抢座；
5. 抢到后弹窗+响铃提醒，注意首页的签到截止倒计时，按时到馆签到。

### v1 其他学校使用说明

- 本项目不绑定任何学校：登录后场馆列表来自平台接口，自动显示你账号所在学校的场馆；
- 微信授权二维码是平台通用入口；如果个别学校的微信授权入口不同，可以**直接复制你在自己微信里「我去图书馆」获取的授权链接**，粘贴到登录框解析，效果相同；
- 如果页面里没有列出你的场馆，请先在手机微信里打开「我去图书馆」确认能正常使用，再重新登录刷新。

### v1 注意事项

- 登录态保存在本地 `data/session.json`，等同于账号凭证，**不要外发、不要提交到仓库**；
- 平台登录态约 2 小时过期，过期后重新扫码登录；
- 遇到平台风控（提示「访问行为异常」）程序会自动停止，建议停一段时间再试；
- 使用时保持电脑不休眠、网络为国内直连（不要挂海外代理）；
- 账号存在因高频/异常行为被平台限制的风险，请自行控制频率。

## 六、仓库目录结构

```
seat-app/
├── v2-wechat/             # v2：PC 微信内置浏览器后台版（推荐）
│   ├── wechat_grab_gui.py # Tkinter 图形界面
│   ├── wechat_grab_v2.py  # 命令行抢座主程序
│   ├── win_backend.py     # Win32 后台抓图 + 消息点击 + 座位识别
│   ├── uia_worker.ps1     # Windows UIA 常驻助手
│   ├── test_bg_click.py   # 5 秒无害刷新测试
│   ├── requirements.txt   # Python 依赖（Pillow, numpy）
│   ├── install_deps.bat   # 一键安装 Python 依赖
│   ├── start_gui.bat      # 一键打开图形界面
│   ├── start_monitor.bat  # 一键只监控提醒
│   ├── start_live.bat     # 一键自动抢座
│   ├── start_fast.bat     # 一键冲刺抢座
│   └── run_test_click.bat # 一键 5 秒刷新测试
├── server.js              # v1：HTTP 服务 + API + 扫码登录 / 手机快传页
├── session.js             # v1：登录态管理（授权链接换 cookie、查询账号/预约/场馆）
├── grabber.js             # v1：抢座核心（Playwright 真实点击）
├── cancel.js              # v1：取消预约（真实点击）
├── tunnel.js              # v1：Cloudflare Tunnel 公网访问
├── public/                # v1：前端控制台页面 + 微信授权二维码
├── 启动.bat                # v1：一键启动脚本
└── data/                  # 运行时生成（登录态等，不入库）
```

# 我去图书馆 · 抢座助手（v2 PC 微信后台版 + v1 浏览器版）

> 支持任意使用「我去图书馆」平台的学校与场馆。
> 仓库现同时保留 **v2（PC 微信内置浏览器后台版，推荐）** 与 **v1（Playwright 本机 Chrome 版）**，请先查看下方对比后再选择使用。

---

## 版本选择：v2 vs v1 优缺点对比

| 对比项 | **v2：`v2-wechat/`（推荐）** | **v1：根目录 Playwright 版（保留）** |
| :--- | :--- | :--- |
| **运行载体** | 电脑微信内置浏览器独立小窗（真实微信环境 + 原生登录态） | Playwright 启动本机 Chrome + 手动粘贴授权链接 |
| **平台环境检测** | **极低风险**：100% 原生微信环境，无任何浏览器自动化注入特征 | **较易触发拦截**：脱离微信环境，实测容易触发「检测到访问行为异常，请求已拦截」 |
| **桌面干扰** | **零鼠标占用、不抢焦点**：`PrintWindow` 后台抓取 + `SendMessage` 消息点击，小窗可被其他软件完全遮挡 | 需维持受控 Chrome 实例运行 |
| **定位与精准度** | Windows UIA 实时读取按钮、全部座位号及弹窗文案，支持 `--prefer` 指定座位号、二次帧确认与「加载中」防误判 | 依赖网页自动化选择器 |
| **交互界面** | 桌面 Tkinter 图形界面（实时后台预览、空座标注、日志与热键 `F9`/`F10`）+ 命令行 | 内置 Web 控制台，支持局域网 / Cloudflare Tunnel 手机远程操作 |
| **适用系统/前置** | **仅 Windows 10/11 + PC 微信 4.x**；需手动在微信里进座位图并弹出小窗 | Windows 10/11 + Chrome（提供免安装打包版） |
| **额外能力** | 专注后台蹲守、自动选座确认、风险弹窗熔断 | 自带自动加载场馆列表、取消预约、公网远程控制 |

### 怎么选？

- **日常稳定抢座优先选 v2（`v2-wechat/`）**：
  - **优点**：完全跑在真实 PC 微信内，绕开了无头/外部浏览器环境指纹问题；不需要占着半个屏幕，也不抢鼠标和键盘焦点；能读懂页面「加载中」状态与弹窗报错文案并及时熔断。
  - **缺点**：只支持 Windows 10/11 + PC 微信 4.x；不支持手机网页远程控制或无桌面服务器；需要自己先在微信点开目标场馆座位图并点一次弹出独立小窗；运行期间小窗**不能最小化到任务栏**，电脑不能锁屏或休眠。
- **需要手机远程操控 / 取消预约 / 免装 Python 可参考 v1（根目录）**：
  - **优点**：开箱即用的 Web 控制台（支持 Cloudflare Tunnel 手机远程看状态/取消预约），有免安装打包版，不依赖 PC 微信常驻挂机。
  - **缺点**：由于不在真实微信内置浏览器中运行，**新老账号均更容易触发平台风控拦截甚至短期封禁**；授权登录态约 2 小时过期，需要重新粘贴授权链接。

## v2 使用说明与操作流程（`v2-wechat/`，推荐）

### 1. 工作原理

1. 由用户在 PC 微信内置浏览器手动进入目标场馆座位图，并点击右上角 `[↗]` 弹出为独立小窗（保留 100% 真实微信运行环境与登录态）；
2. 通过常驻 Windows UIA（无障碍接口）读取网页 DOM，动态获取「刷新」「确认选座」、全部座位编号位置以及弹窗提示文案（无需硬编码坐标，也不需要维护模板文件）；
3. 通过 Win32 `PrintWindow` 直接抓取独立小窗画面（**即使小窗被其他软件完全遮挡也能清晰抓图**），等待「加载中」遮罩消失后准确识别每个座位状态；
4. 通过 `SendMessage` 向渲染窗口发送后台点击消息（**不移动真实鼠标、不抢焦点**），在 `live` 模式下对空座做 80ms 二次帧确认 → 点选座位 → 60ms 轮询验证变绿 → 点击「确认选座」→ 读取弹窗文案判断成功或风控熔断。

### 2. 环境要求与安装

- Windows 10 / 11
- 电脑版微信 4.x（`Weixin.exe`）
- Python 3.10+（需包含标准库 `tkinter`）

安装 Python 依赖（仅需 `Pillow` 与 `numpy`）：

```bash
cd v2-wechat
pip install -r requirements.txt
```

### 3. 操作流程（4 步）

1. **打开并登录 PC 微信**。
2. **进入座位图页面**：在微信内打开「我去图书馆」网页 → 点击「去选座」→ 点进目标场馆，停留在能看到座位图和底部「确认选座」的页面。
3. **弹出独立浏览器小窗**：点击微信内置浏览器标签栏右上角的 **`[↗]`** 按钮弹出独立小窗：
   - 弹出后可任意拖动位置，**可以直接压在其他工作/视频窗口底下**（微信主窗口缩到托盘也没关系）；
   - **不要点最小化（`—`）**，最小化到任务栏会暂停渲染。
4. **启动助手**：
   - **图形界面（推荐）**：双击 `v2-wechat/start_gui.bat`
     - 顶部显示 `已连接 · XXX座` 后，选择 **仅监控提醒 (Monitor)** 或 **自动抢座 (Live)** 与刷新节奏，点击 **「▶ 开始运行」**；
   - **命令行模式**：
     - `v2-wechat/start_monitor.bat`：仅监控蹲守（`0.8~1.5s` 随机刷新，发现空座响铃+截图，不点预约）；
     - `v2-wechat/start_live.bat`：自动抢座（`0.8~1.5s` 随机刷新）；
     - `v2-wechat/start_fast.bat`：冲刺模式（`0.4~0.8s` 随机刷新，仅建议放座高峰短时使用）。

### 4. 首次安全验证与常用技巧

- **5 秒无害刷新测试**：首次使用建议先双击 `v2-wechat/run_test_click.bat`。该脚本**只会点 3 次「刷新」按钮，绝不点击任何座位或「确认选座」**，用于验证当前环境下 `PrintWindow` 后台抓图、UIA 座位识别和零鼠标点击是否正常。
- **全局热键**：运行期间在任意窗口按 **`F9` 暂停**、**`F10` 继续**。
- **命令行常用参数**（`python wechat_grab_v2.py`）：
  - `--prefer 001,002`：优先抢指定座位号，留空则从空座中随机抽取
  - `--safe`：稳健节奏（`2.0~3.5s` 随机间隔）
  - `--fast`：冲刺节奏（`0.4~0.8s` 随机间隔）
  - `--interval-min 1.0 --interval-max 2.0`：自定义随机间隔区间
  - `--minutes 120`：运行时长（`0` 表示不限时）
  - `--no-beep`：静音模式

## 风险与局限性（重要，使用前必读）

1. **平台风控与封号风险（最关键）**：
   - 即使运行在真实 PC 微信内置浏览器内，平台除了校验环境外，同样存在**访问频率与操作行为风控**；
   - 长时间使用过快间隔（如持续 `< 0.8s`）、或账号在受限期间反复提交「确认选座」，仍可能导致「检测到访问行为异常」拦截甚至账号短期封禁；
   - 建议平时蹲守使用 `0.8~1.5s`（或 `--safe` `2.0~3.5s`），仅在放座高峰短时开启 `--fast`；**一旦程序触发风控熔断停止，请立刻停手并查看 `v2-wechat/shots/` 中的最后一张截图**，切勿强行连续重试。
2. **操作系统与窗口状态限制**：
   - v2 依赖 Windows Win32 API（`PrintWindow` / `SendMessage`）及 Windows UI Automation，**仅支持 Windows 10/11**（不支持 macOS / Linux）；
   - 独立浏览器小窗**可以被遮挡，但绝不能最小化到任务栏**，且电脑**不能锁屏或进入睡眠**，否则 DWM 会停止窗口渲染导致截图空白；
   - 部分带「正在检测/需要前台」场景或系统 UAC 弹窗会中断后台抓取。
3. **前端改版与微信版本兼容风险**：
   - v2 依赖微信 4.x 的窗口结构（`Weixin.exe` / `WeChatAppEx.exe`、`Chrome_RenderWidgetHostHWND`）以及目标网页的中文文本标识（「刷新」「确认选座」）与座位方块配色；若微信大版本重构浏览器内核或平台更换前端配色/文案，可能需要更新选择器或阈值。
4. **大场馆可视区域限制**：
   - `PrintWindow` 只能截取当前浏览器视口内渲染出的座位。若目标场馆座位较多，弹出独立小窗后请适当拉大窗口尺寸，确保你关注的座位区域全部出现在预览画面中（不要被滚动条裁掉）。
5. **合规提醒**：
   - 本项目仅供个人学习 Windows 自动化与交流使用，请严格遵守平台与图书馆规章制度。

## v1：Playwright 浏览器版（保留，按需选用）

> 基于 Playwright 驱动本机真实 Chrome 模拟点击的早期版本。支持任意使用「我去图书馆」平台的学校与场馆，自带 Web 控制台与手机远程控制。

### v1 功能

- **微信授权登录**：手机微信扫「微信授权二维码」→ 复制带 `code=` 的链接 → 粘贴解析登录（也可用手机快传）
- **自动加载场馆**：登录后自动读取你所在学校的场馆列表（不同学校各自显示自己的场馆）
- **首页控制台**：账号信息、当前预约、签到截止倒计时、数据刷新
- **抢座**：监控官方座位图，发现空座后点击座位 → 确认选座（全程真实点击）
- **自动保护**：预约被平台风控拦截时自动停止；抢到后自动停止并提醒
- **取消预约**：在官方网页上点「取消预定」→「确定」（真实点击）
- **远程控制**：手机浏览器打开同一页面即可远程操作（局域网 / Cloudflare Tunnel 公网均可）
- **实时日志**

### v1 工作原理

程序用 Playwright 驱动本机真实 Chrome，**打开官方网页，所有平台请求都由页面自己发出**：

1. **登录**：用真实浏览器打开微信授权接口完成换 cookie，登录与后续使用处于同一浏览器环境；
2. **抢座**：模拟真人进入流程（首页 → 选座 → 座位图），点击页面「刷新」→ 发现空座 → 点击座位 → 点击「确认选座」；
3. **数据读取**（账号/预约/场馆）：真实浏览器打开官方网页，由页面自己请求，程序只读取页面请求的响应；
4. **取消预约**：点击「取消预定」→「确定」。

> 浏览器使用本机 Chrome 原生 UA（不伪造），并做基础反自动化特征处理；不直接调用平台 GraphQL 接口。

### v1 环境要求

#### 免安装版（见下方「下载即用」）

- Windows 10/11
- Google Chrome（程序使用本机 Chrome 打开官方网页）
- 内置 Node.js 与 cloudflared，无需额外安装

#### 源码运行

- Windows 10/11
- Node.js 18+
- Google Chrome（Playwright 使用本机 Chrome）
- （可选）`cloudflared.exe`：用于公网访问功能，放到 `bin/cloudflared.exe`，可从 Cloudflare 官方 GitHub Releases 下载

### v1 下载即用（免安装版）

不想安装 Node.js 环境？可直接下载 v1.0.3 发布包（注意：v1 目前较易受平台风控影响，建议优先尝试 v2）：

- **[seat-grabber-v1.0.3-win-x64.zip](https://github.com/Moonlight-1210/Igolibrary-Simulated_click/releases/download/v1.0.3/seat-grabber-v1.0.3-win-x64.zip)**（约 53 MB）
- 解压后双击 `启动.bat` 即可运行（内置 Node.js，需要本机装有 Google Chrome）

启动后会自动打开浏览器控制台；若没有自动打开，手动访问 http://127.0.0.1:7789

### v1 安装与运行

```bash
npm install
npm install playwright-core
```

双击 `启动.bat`，或命令行运行：

```bash
node server.js
```

启动后会自动打开浏览器控制台；若没有自动打开，手动访问 http://127.0.0.1:7789

### v1 使用步骤

1. 点「登录」→ 手机微信扫微信授权二维码 → 完成授权 → 复制跳转后带 `code=` 的链接 → 粘贴 → 「从链接解析登录」；
2. 登录成功后，场馆下拉框会**自动加载你所在学校的场馆**，选择一个场馆；
3. 设置刷新间隔（默认 1~1.5 秒）、运行时长（默认 60 分钟）；
4. 点「开始抢座」，程序会在官方网页上真实点击抢座；
5. 抢到后弹窗+响铃提醒，注意首页的签到截止倒计时，按时到馆签到。

### v1 其他学校使用说明

- 本项目不绑定任何学校：登录后场馆列表来自平台接口，自动显示你账号所在学校的场馆；
- 微信授权二维码是平台通用入口；如果个别学校的微信授权入口不同，可以**直接复制你在自己微信里「我去图书馆」获取的授权链接**，粘贴到登录框解析，效果相同；
- 如果页面里没有列出你的场馆，请先在手机微信里打开「我去图书馆」确认能正常使用，再重新登录刷新。

### v1 注意事项

- 登录态保存在本地 `data/session.json`，等同于账号凭证，**不要外发、不要提交到仓库**；
- 平台登录态约 2 小时过期，过期后重新扫码登录；
- 遇到平台风控（提示「访问行为异常」）程序会自动停止，建议停一段时间再试；
- 使用时保持电脑不休眠、网络为国内直连（不要挂海外代理）；
- 账号存在因高频/异常行为被平台限制的风险，请自行控制频率。

## 仓库目录结构

```
seat-app/
├── v2-wechat/             # v2：PC 微信内置浏览器后台版（推荐）
│   ├── wechat_grab_gui.py # Tkinter 图形界面
│   ├── wechat_grab_v2.py  # 命令行抢座主程序
│   ├── win_backend.py     # Win32 后台抓图 + 消息点击 + 座位识别
│   ├── uia_worker.ps1     # Windows UIA 常驻助手
│   ├── test_bg_click.py   # 5 秒无害刷新测试
│   ├── requirements.txt   # Python 依赖（Pillow, numpy）
│   ├── start_gui.bat      # 一键打开图形界面
│   ├── start_monitor.bat  # 一键只监控提醒
│   ├── start_live.bat     # 一键自动抢座
│   ├── start_fast.bat     # 一键冲刺抢座
│   └── run_test_click.bat # 一键 5 秒刷新测试
├── server.js              # v1：HTTP 服务 + API + 扫码登录 / 手机快传页
├── session.js             # v1：登录态管理（授权链接换 cookie、查询账号/预约/场馆）
├── grabber.js             # v1：抢座核心（Playwright 真实点击）
├── cancel.js              # v1：取消预约（真实点击）
├── tunnel.js              # v1：Cloudflare Tunnel 公网访问
├── public/                # v1：前端控制台页面 + 微信授权二维码
├── 启动.bat                # v1：一键启动脚本
└── data/                  # 运行时生成（登录态等，不入库）
```
